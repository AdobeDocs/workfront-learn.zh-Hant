# 更新準確報告的任務狀態 — 共用

影片會提供教學課程，說明更新任務狀態的方式、原因和頻率。

>[!VIDEO](https://video.tv.adobe.com/v/3471178/?captions=chi_hant&quality=12&learn=on&enablevpops=1)

## 重點提要

* **您應該如何更新工作狀態？** 您可在幾個位置更新任務狀態。 最常見的是專案頁面上的任務清單。
* **更新工作狀態為何重要？** 及時且準確的專案和任務報告完全取決於來自個別貢獻者的狀態更新。 沒有一致的更新，可見度就會受影響、決策會陷入停滯，而且進度風險也會偏離軌道。
* **您應該多久更新一次任務狀態？：**&#x200B;在每個工作日結束時更新您正在處理的所有任務的狀態。 這可讓專案與任務報告在一天內保持準確。
