# 將問題或請求轉換為專案 — 共用

影片示範如何將問題或請求轉換為專案。

>[!VIDEO](https://video.tv.adobe.com/v/3446633/?captions=chi_hant&quality=12&learn=on&enablevpops=1)

## 重點提要

* **轉換程式：**&#x200B;若要將問題或請求轉換為專案，請選取問題、使用三點功能表，並選擇轉換選項，最好使用範本。 &#x200B;
* **範本選擇：**&#x200B;建議您使用範本以保持一致且容易進行。 您&#x200B;可以根據專案要求檢閱並選取適當的範本。 &#x200B;
* **專案詳細資料：**&#x200B;專案名稱和描述預設是從問題中複製而來，但可以編輯。 問題中的&#x200B;自訂表單也會轉存到專案。 &#x200B;
* **問題解決：**&#x200B;您可以選擇將原始問題繫結至專案，防止在專案完成前將其標示為已解決。 或者，&#x200B;可以在轉換時刪除問題。 &#x200B;
* **存取與可見性：**&#x200B;您可以授與要求者專案的存取權。 已轉換的專案將顯示在「已轉換&#x200B;為」欄中，指示它是否已轉換為任務或專案。 &#x200B;
